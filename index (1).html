Hospital Management and Emergency Care: OS Visualizer

One hospital scenario, four OS mechanisms. Patient requests are produced into a bounded buffer, scheduled by priority, checked for safe resource allocation with Banker’s Algorithm, and given memory partitions.

CPU scheduling

Lower priority number means more urgent. Emergency Admission gets priority 1. Edit any value, pick an algorithm (FCFS, SJF, SRTF, Priority or Round Robin), then run.

Producer–consumer (bounded buffer)

Producers: patient registration and lab results arriving. Consumers: diagnostic and processing tasks. Semaphores empty and full count slots; mutex guards the buffer.

Deadlock avoidance (Banker’s Algorithm)

Resources: Imaging equipment, Printers, Database connections. Edit Allocation, Maximum and Available, then check the state. The request form tests whether granting a request keeps the system safe.
